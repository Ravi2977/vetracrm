Unlike off-the-shelf software with a price list, custom software is estimated from the work involved. Here are the factors that move the number up or down.

1. Scope: screens, workflows and rules

The number of screens and the complexity of business rules (approvals, calculations, exceptions) are the biggest drivers of effort.

2. Users and roles

More user types (staff, managers, customers, dealers, suppliers) means more permissions, views and testing.

3. Platforms

Web only, or also mobile and desktop apps? Each platform adds work, though shared backends reduce it.

4. Integrations

Tally, payment gateways, WhatsApp, IndiaMART, hardware and existing systems. Each integration needs design, development and testing. See Tally integration.

5. Design

A polished, custom UI takes more time than a standard admin layout, but improves adoption.

6. Data migration

Moving data from old systems and spreadsheets, cleaning it and verifying it is often underestimated.

7. Testing and launch

Quality testing, user acceptance testing, deployment and training are part of the real cost.

8. Ongoing support

Hosting, monitoring, updates and changes after launch. See what a software AMC covers.
