If you are building a desktop application for your business, your development team will pick a framework. Here is what the common options mean in practice.

Electron

  • What it is: desktop apps built with web technologies (HTML, CSS, JavaScript)
  • Pros: Windows, Mac and Linux from one codebase; modern UI; can share code with a web version
  • Cons: larger install size and higher memory use
  • Good for: apps that also need a web version or a modern look

.NET (WPF, WinUI, MAUI)

  • What it is: Microsoft's platform, strongest on Windows
  • Pros: excellent Windows integration, mature tooling, efficient
  • Cons: Mac support depends on the framework chosen
  • Good for: Windows-only business software and hardware integration

Tauri

  • What it is: web-based UI with a lightweight native core
  • Pros: small installers, lower memory use, Windows and Mac support
  • Cons: younger ecosystem than Electron
  • Good for: lightweight cross-platform tools

Qt

  • What it is: a long-established C++ framework
  • Pros: fast, cross-platform, strong for industrial and device software
  • Cons: licensing and specialised skills
  • Good for: performance-critical or embedded applications
How we choose

We consider which operating systems you need, hardware integrations, whether a web version is planned, and who will maintain the app long term. The best framework is the one that fits your project, not the newest one.
