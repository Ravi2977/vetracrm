Core Web Vitals are three measurements Google uses to judge the experience of loading and using a web page. They matter for users first, and they are also part of how Google evaluates page experience.

LCP: Largest Contentful Paint

What it measures: how long it takes for the main content (usually the hero image or headline) to appear.

Good: 2.5 seconds or less.

How to improve:

  • Compress and correctly size images; use modern formats
  • Use fast hosting and a CDN
  • Avoid large scripts that block the page from showing
  • Preload the most important image or font

INP: Interaction to Next Paint

What it measures: how quickly the page responds when someone taps or clicks. It replaced First Input Delay (FID) in 2024.

Good: 200 milliseconds or less.

How to improve:

  • Reduce heavy JavaScript and third-party scripts
  • Break long tasks into smaller pieces
  • Avoid unnecessary plugins and trackers

CLS: Cumulative Layout Shift

What it measures: how much the page jumps around while loading. You have felt this when you try to tap a button and it moves because an image or banner loaded above it.

Good: 0.1 or less.

How to improve:

  • Always set width and height (or aspect ratio) on images and videos
  • Reserve space for banners, ads and embeds
  • Avoid inserting content above existing content after load
  • Load web fonts so the text does not reflow (for example, matching fallback font metrics)
Example from our own site

We build pages with fixed image sizes, preloaded fonts with matched fallbacks, and content that is visible from the first paint. Our own pages measure a CLS of 0 in testing.

How to check your site

Use PageSpeed Insights for a quick report, and Google Search Console's Core Web Vitals report to see real-user data across your site.
