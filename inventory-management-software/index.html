Ask a question
Can I track IMEI and serial numbers?

Yes. Serial numbers or IMEIs are recorded on purchase and sale, so you can see where each unit came from and who bought it.

Does it handle warranty?

Yes. You can check a product's warranty using its serial number and log service or replacement requests.

Can I manage more than one shop or godown?

Yes. Stock is tracked per location, and you can transfer stock between locations.

Does it include GST billing?

Yes. GST invoices are created from the same software and stock updates automatically.

Is there a desktop version?

Yes. Vetra Inventory is available as Windows desktop software and as a cloud version.

How much does inventory software cost?

Pricing depends on the version, number of users and locations, and setup. Book a free demo and we'll send a written quote.
