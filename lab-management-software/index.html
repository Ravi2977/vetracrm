Ask a question
Can patients get reports on WhatsApp?

Yes. Approved reports can be shared as PDF on WhatsApp or email, so patients and doctors don't need to collect a printout.

Can I use my own report format and letterhead?

Yes. Report templates are set up with your lab's letterhead, signatures and notes during setup.

Does it support test packages and discounts?

Yes. You can create packages, apply discounts and track advance and due payments.

Can it calculate doctor referral reports?

Yes. Referring doctors are recorded with each bill and referral reports can be generated for any period.

Is there a desktop version?

Yes. Vetra Lab is available as Windows desktop software and as a cloud version for labs with multiple centres.

How much does lab management software cost?

Pricing depends on the version, number of users or centres, and setup. Book a free demo and we'll send a written quote.
